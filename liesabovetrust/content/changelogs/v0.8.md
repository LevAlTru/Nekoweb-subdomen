### Changes:
- Pages now can be lavender or golden (purple and yellow).
    - Changelogs are now golden.
    - Intermediate pages like [/assets](/./assets) are now golden.
    - `--sel-col` now depends on the color of the page.
    - Scroll color now depends on the color of the page.
- JS files are no longer wrapped with window.onload event, which means that their functions can be used in the console.
- Moved `data.json` over to Github repository because i am too scared that i will accidentally wipe some data while moving local and uploaded website instances. That way no matter what happens to local and uploaded instances, the data should remain intact.
- [Clocks]({{< ref "/clocks" >}}) with links now have a hover tint.
- Happy spots.
- Added a button to backtrack from changelogs and intermediates.

### Fixes: 
- Fixed `data.json` being cached on clients, resulting in outdated data.
- Main page: Fixed Latest Updates using the range of [0, 11] instead of [1, 12] for months.
